# Enaam Ali Osman - Documentary Photographer Portfolio

Portfolio website of Enaam Ali Osman, a documentary photographer and visual storyteller documenting humanitarian, community, and social advocacy initiatives.

## Features

- **React + TypeScript + Vite**: Fast, modern, modular Single Page Application.
- **Full Bilingual (Arabic & English) Support**: Instant toggle with dynamic RTL/LTR layout, typography alignment, and localized metadata.
- **Documentary Series Showcases**:
  - Independent interactive photo viewers for each series.
  - Filmstrip thumbnail navigation with lazy loading and eager prefetching.
  - Directional navigation and responsive image viewing.
- **Cinema Fullscreen Lightbox**:
  - Immersive cinema-grade fullscreen modal.
  - Keyboard navigation (Esc, Arrow Left, Arrow Right).
  - Touch-swipe gestures for mobile devices.
  - Fullscreen toggle via HTML5 Fullscreen API.
- **Visual Atmosphere**:
  - Golden lens halo effects, arched vault portrait card, subtle gold particle field.
  - Smooth custom cursor on non-touch screens.
- **Direct Contact & Inquiry Form**:
  - Form validation with direct formatted mailto link creation and confirmation toast notice.

## Running the Project

```bash
npm install
npm run dev
```

Build for production:
```bash
npm run build
```
